# Containerizing-a-basic-application
We can take advantage of this setup to create an image using docker build . which will give us an image id or by knowing the generated name using docker ps and then we can run the application in the container using the exposed port and mount it on the host machine port by using docker run -p 3000:3000 (name/id of the container) here i simulated a connection to database just because the purpose of this application is to act as a guideline on how we should work with containerizing the application.
